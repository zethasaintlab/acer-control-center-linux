# Product and Visual Quality

The target is a coherent industrial-technical hardware command center informed by the Endfield Design System research in docs/DESIGN_SYSTEM.md.

A redesign changes the product experience, not merely its palette. Evaluate:
- Information architecture and workspace responsibilities.
- Navigation model and orientation.
- Screen composition, data hierarchy and information density.
- Reusable component language and interaction behavior.
- Loading, unavailable, stale, unsupported, preview, error and success states.
- Typography, geometry, surfaces, technical decoration and semantic color.

Reject a color-only reskin of the former Precision Hardware Atelier layout. Do not preserve the old page composition merely because its colors and labels can be changed.

Use Endfield's industrial/tactical and CAD-like design principles as inspiration, not as an exact UI template. Avoid copied assets, logos, proprietary artwork and decorative noise. Adapt the reference palette to accessible, semantic application tokens; custom app accent remains independent from physical keyboard RGB.

Use DAMX to study useful hardware-management workflows and information grouping, not as a visual target or hardware compatibility authority.

No fabricated telemetry, decorative gauges, false capability badges, nested-card clutter, arbitrary gradients, excessive glow, purposeless animation or inaccessible custom controls. Every visual element must clarify state, hierarchy or action.
